# MemeVerse Characters

i wanted to make a platform for memes where users can browse / scroll a lot of memes characterized by The CHARACTERS (that can be real or fictious) 
these characters will have accounts just like Insta Accounts but no one is actually operating them.
OPERATIONS -
1. Users can search memes on the basis of CHARACTERS
2. Users can submit links of such memes already available on Other platforms like YT or insta(that can be seen as PIP so that i dont need a cloud dedicated to store memes - similar to SMooche dating app reels feature)
3. A feed section where popular trending meme CHARACTERES at that time are shown with their memes.

WHAT MAKE IT DIFFERENT- I need strong algorithm for accurate results as user search memes
